# グループ別の修飾率

1. 「読み込み」で、各サンプルの基本配列と修飾配列を読み込みます。
2. 「修飾率」のサンプル一覧で所属させたいサンプルを複数選択します。
3. 「グループ名・所属を設定 / 保存・読込」を開き、名前を入力して「追加」を押します。空欄の場合は Group A、Group B…を設定します。ダイアログ内でも所属を選択できます。
4. 必要な数のグループを追加し、「適用してグループ別に評価」を押します。1グループの評価から利用できます。
5. ターゲット・補正・集計方法を確認して「計算」を押します。グラフと表は登録した全所属サンプルで集計します。主画面のサンプル選択・検索によって所属の一部が外れることはありません。

同名サンプルでも実験名が違えば別のサンプルとして扱います。同じサンプルの重複所属は禁止します。設定はJSONで保存・読込できます。編集するグループを選び「選択行を更新」で変更します。設定の適用には所属サンプルの読み込みが必要です。

## 集計方法

- **サンプル修飾率の平均（標準）**：各サンプルの修飾率を同じ重みで平均します。測定行数の違いで重みが変わりません。
- **行数を合算**：全有効サンプルの修飾行数の合計を、分母となる全行数の合計で割ります。測定行数の多いサンプルの寄与が大きくなります。

グループの95%区間は、所属する有効サンプルを単位に1,000回復元抽出し、同じ集計方法で計算した率の2.5・97.5パーセンタイルです。サンプル単位で率を再計算するので、グループ別では単体用のWilson・ファイル単位ブートストラップ設定は使いません。有効サンプルが1つの場合、率だけを表示し区間は算出しません。

基本配列が未読込、修飾位置の行がない、修飾配列が未読込などのサンプルは、該当修飾の集計から除外します。有効数・登録数と所属一覧を表・CSVに残します。有効数ゼロの組み合わせは率を算出できません。同じ位置に複数の修飾配列がある場合は、従来と同じくそれらも分母に含めます。

0%・100%対照は従来と同じく読み込み済みのサンプルから指定します。同一修飾の対照率でグループ率と区間を線形変換します。対照側の不確実性は区間に含みません。対照なし・範囲不正の場合は補正率を算出しません。

表の修飾行・未修飾行・ファイル数は、有効サンプルの合計です。棒の中の行数も合計なので、「サンプル修飾率の平均」を選んだ場合、表示された合計行数の比と棒の高さは一致しない場合があります。行を選ぶと、有効サンプルの値を合算した分布を表示します。

「表をCSV保存」で、グループ名・全所属・有効所属・有効数・集計方法・区間の方式・補正対照・Q下限などを保存します。元データと設定を確認できるよう、グループ定義JSONも保存しておくと便利です。グループ評価は記述的な比較で、群間差の検定は行いません。
