    		status

    ステータスは、エラーが発生した場合はTRUE（X）、警告が発生した場合またはエラーなしの場合はFALSE（チェックマーク）になります。

    フロントパネルにあるエラー入力制御器を右クリックして、ショートカットメニューからエラーの説明または警告の説明を選択すると、エラーの詳細が表示されます。

    		code

    コードは、エラーまたは警告コードです。

    		source

    ソースは、エラーまたは警告が発生した場所を示します。
