# 教師なし学習

Tkinterアプリの「教師なし学習」内の「① データ精査・絞り込み」で抽出済みデータを読み込み、必要に応じてファイルを絞り込み、上部の「③ クラスタリング設定・実行」を押します。既存の精査タブと同じ抽出版・実験選択、ファイル条件を使用します。設定・結果は同じ画面内の「② クラスタリング・評価」タブに表示します。タブを切り替えても設定・結果は保持します。上部ボタンを再度押すと、現在の精査対象を取り込んで設定・結果を初期化します。解析中は対象を更新できません。

使用特徴量を選び、手法・前処理を設定して実行します。サンプル名、ファイル名、実験ID、イベントID・位置情報は学習に使用しません。精査画面と同じ保存済みメタ情報・波形特徴量が対象です。tsfreshの追加計算や、別ファイルのChronos埋め込みとの結合は行いません。

- K-means／Ward階層法：2〜指定最大数のシルエット係数を比較し、最大の数を推奨。
- Gaussian Mixture：1〜指定最大数のBICを比較し、最小の数を推奨。
- DBSCAN：epsとmin_samplesで密度を指定し、数を自動決定。-1はノイズです。数の直接指定は無効です。

`auto`を整数に変更すると手動指定で再実行できます。推奨数は探索範囲内の相対評価で、正解数を保証しません。シルエット係数は最大2000イベントで計算し、DBSCANではノイズを除外します。評価不能な値は空欄です。

標準化はstandard／robust／none、欠損値は中央値補完／行除外を選択できます。全欠損・定数列は除外し、選択特徴量がすべて欠損の行も除外します。上限を超えるイベントは固定乱数42で抽出し、解析したイベントだけを保存します。学習は前処理後の特徴量空間で行い、PCAは表示専用です。階層法・DBSCANはデータ量によってメモリ消費が大きくなるため初期上限は5000件です。

結果は `ML/cluster_results/<日時>/` に保存します。

- `events.csv`：元の行番号、元ファイル・サンプル情報、クラスタ、PCA座標
- `candidate_scores.csv`：候補数と評価値（K-meansはinertiaも保存）
- `sample_clusters.csv`：サンプル別クラスタ件数
- `feature_summary.csv`：クラスタ別特徴量統計
- `conditions.json`：特徴量・前処理・抽出版・絞り込み・推奨数と採用数
- `clustering.png`：PCA散布図と評価曲線
- `feature_distributions.png`：先頭6特徴量のクラスタ別ヒストグラム（補完前の観測値）
