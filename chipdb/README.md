# Chip Atlas

Quantum Workbenchランチャーの「Chip Atlas」（キー7）、または `python chipdb/app.py` で起動します。追加ライブラリは不要です。

初回はAXNと同じ `AXN_LABVIEW_ROOT` または `%LOCALAPPDATA%/AXN/settings.json` の `shared_data_root` を参照します。「共有フォルダを選択」で共有ルート、ChipDB、DBのいずれかを指定できます。選択はPCごとの `%LOCALAPPDATA%/QuantumWorkbench/chip_atlas.json` に保存され、次回以降はこの場所を優先します。一時的に接続できなくても別の場所には切り替えません。

- 左の検索欄一つでチップ名・使用日を検索。`2026`（年）、`2026-11` / `202611`（年月）、`2026-11-13`（日）、`2026-10〜2026-11`（期間）を入力できます。`2026年11月` や `/` 区切りにも対応。空欄で全件表示
- 使用日は各CSVのExperiment行の実験日を検索します。ファイル更新日や初回〜最終日の間を使用日と見なしません。日付一覧はバックグラウンドで読み込み、検索欄の下に処理中・件数を表示。AXN側で履歴が増えたら「再読み込み」で更新
- 全履歴表示、実験数・操作数・GAPの概要
- 「チップ概要」: AXNのChip data相当。GPSET/EXSV/CAL/FC/MA/TA件数、初回・最終日時、最新値・平均・標本標準偏差、FC初回値、M/T、最終装置・担当者・抵抗を表示
- 「全チップ比較」→「全チップを集計 / 更新」: 全CSVをバックグラウンドで集計。全項目検索、列見出しで並べ替え、CSV出力、行のダブルクリックで個別概要へ移動
- 左のチップID一覧と全チップ一覧は選択が連動します。どちらもシングルクリックで上部のチップ名・概要・履歴・編集対象を切り替えます。全チップ一覧のダブルクリックは個別概要へ移動。並べ替えても同じチップの選択を維持し、検索で非表示になった場合は以前の行を誤って選択しません
- 全チップ比較内の「分布・装置・担当者」: AXN相当の7種の分布（50区間）と装置・担当者別チップ数。検索で絞り込んだ対象を表示。読めなかったファイルは「読み込みエラー」に分離
- 操作別・Info列別の数値トレンド（記録順）、最小・最大・平均
- 行のダブルクリックで編集。行種別・行数・列数は維持
- CP932とCRLFで共有元へ保存。バックアップは `ChipDB/WorkbenchBackups`
- 読み込み後の外部変更を検知すると保存を拒否。再読み込みして編集し直してください
- UTF-8 BOMのCSVを書き出し可能

## 編集・チェックイン

- 上部の「＋ チェックイン」、または「チップ台帳・チェックイン」タブから測定前のチップを登録します。状態・保管場所・使用者・作成元・作製日・使用開始日・廃棄日・説明を保存できます。日付は `YYYY-MM-DD`、未定は空欄です
- チェックインはAXNの先行登録と同じく共有ルートの `machinedb/PLAN/chip_info.json` に登録します。測定履歴CSVやGPSET、GAPは作成しません。新規IDの区切り文字はAXNと同じ形式（`-`）に統一します
- 履歴のない登録チップも左の一覧に表示します。選ぶと台帳タブを開きます。使用日検索は実際のExperiment行が対象なので、履歴のないチップは名前検索または空欄で表示してください
- 台帳で行を選び「選択チップの管理情報を編集」、またはダブルクリックで登録情報を修正できます。既存CSVのみのチップも管理情報を保存すると共有台帳に登録され、元CSVは維持されます
- 測定履歴の修正は「操作履歴・編集」で行を選び「選択行を編集」（またはダブルクリック）。元CSVをバックアップして保存します
- 複数行・列の修正は「操作履歴・編集」→「表全体を編集」。セルをダブルクリックして修正、Shift/Ctrlで行を範囲選択し、対象列の完全一致置換または同じ値の設定ができます。「全行」を指定すれば列全体が対象になります
- GAP列は先頭行の集計値とExperiment行を編集できます。日付のような異常値でも正しいGAP数は推測せず、確認した値に置換してください。先頭行と各操作行のGAPが同じとは限らないので、列全体を一つの値に揃える操作は必要な範囲だけに限定してください
- Excel等でGAP列の値を編集してコピーし、貼り付け開始の行をクリック、対象列を「GAP #」にして「貼り付け」で縦一列を反映できます。複数列のタブ区切り貼り付けにも対応。行数・列数、種別・チップID・見出しは保護します
- 表全体の変更は下書きで、「元に戻す」が可能。「変更内容を確認して保存」で行・列・変更前後を一覧確認し、保存ボタンを押すまで元CSVは変わりません。保存時にバックアップと外部更新チェックを行います。編集対象は選択した1チップの履歴全体です
- 台帳はAXNと同じ `chip_info.lock`・revisionを使って保存し、変更前の全台帳を `machinedb/PLAN/backups` にバックアップします。外部更新・重複チップ・競合候補ファイルを検知した場合は保存を停止します
- 全チップ比較は履歴CSVがあるチップを対象にします。AXNのChip Masterは保存済みスナップショットを表示するため、CSV履歴を編集した後にAXNへ反映するにはAXN側の「ChipDBの差分を確認・取込」を使ってください

Infoの意味と単位は操作によって異なります。トレンドグラフは数値の単純集計です。履歴CSVはAXNとの排他ロックを共有していないため、測定中の同時編集を避けてください。GPSETの作成・編集はAXNで行います。

チップ概要・全チップ比較の集計値はAXNの `panel_info.py` に合わせ、Info1の `0 < CAL < 200`、`0 < FC < 3`、`0 < MA/TA < 100` だけを採用します。最新値は有効値のうちファイル順で最後の値です。操作件数には除外値の行も含めます。全チップ集計は取得時点の表示なので、編集やAXNでの測定後は集計を更新してください。スコア・外部解析結果の結合はまだ含みません。
