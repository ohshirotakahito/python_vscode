# Chip Atlas

Quantum Workbenchランチャーの「Chip Atlas」（キー7）、または `python chipdb/app.py` で起動します。追加ライブラリは不要です。

初回はAXNと同じ `AXN_LABVIEW_ROOT` または `%LOCALAPPDATA%/AXN/settings.json` の `shared_data_root` を参照します。「共有フォルダを選択」で共有ルート、ChipDB、DBのいずれかを指定できます。選択はPCごとの `%LOCALAPPDATA%/QuantumWorkbench/chip_atlas.json` に保存され、次回以降はこの場所を優先します。一時的に接続できなくても別の場所には切り替えません。

- 起動時は「チップ台帳・比較」を表示します。測定前も含めた全チップの入口です。
- 2026-11-18 から、以前の「チップ台帳・チェックイン」と「全チップ比較」を 1 つの表にしました。1 チップ 1 行で、AXN共有台帳の管理情報（状態・保管場所・使用者・作製日・使用開始日）と、履歴CSVの集計（GAP・実験数・CAL・FC・MA・TAなど）を並べます。「表示する列」で「管理情報」「測定の集計」「すべて」を切り替えます。「管理情報」には製作者・主体と、工程の最新値（FC・MA・TA・CAL）も入れています。列見出しで並べ替えると、空欄（測定前など）は昇順・降順のどちらでも最後に並びます。列の幅は見出しと中身の長さに合わせて詰め、数値は右寄せにします。台帳とCSVは 1 対 1 なので、表を分ける必要がありません。
- 検索欄でチップID・管理情報・集計値（装置・測定者など）・使用日を検索。`2026`（年）、`2026-11` / `202611`（年月）、`2026-11-13`（日）、`2026-10〜2026-11`（期間）を入力できます。`2026年11月` や `/` 区切りにも対応。空欄で全件表示
- 使用日は各CSVのExperiment行の実験日を検索します。ファイル更新日や初回〜最終日の間を使用日と見なしません。日付一覧はバックグラウンドで読み込み、検索欄の下に処理中・件数を表示。
- 「一覧・履歴・集計を更新」でCSV一覧と台帳を読み直します。履歴CSVは**変わったファイルだけ**を読み直します（全ファイルの更新日時・サイズを調べ、前回と同じものは控えの集計を使う。3501 件で、初回 約 3 秒、2 回目以降 約 0.2 秒。2026-11-18 このPCで計測）。1 回の読み込みで集計と使用日の両方を作ります。起動時は前回の控えをすぐ表示し、裏で差分を確かめます。選択中のチップは維持します。
- 控えは PC ごとの `%LOCALAPPDATA%/QuantumWorkbench/chip_atlas_cache/` に置きます（共有フォルダには書きません）。集計の決まり（`summary.py`・`search.py`）が変わると自動で全件を読み直します。同期の都合で中身が変わっても更新日時とサイズが同じ、というまれな場合に備え、「全件読み直し」ボタンもあります。
- 全履歴表示、実験数・操作数・GAPの概要
- 「チップ概要」: AXNのChip data相当。GPSET/EXSV/CAL/FC/MA/TA件数、初回・最終日時、最新値・平均・標本標準偏差、FC初回値、M/T、最終装置・担当者・抵抗を表示
- 列見出しで並べ替え（もう一度押すと逆順）、表示中の列で「表示一覧をCSV出力」、行のダブルクリックで個別概要へ移動
- クリックで上部のチップ名・概要・履歴・編集対象を切り替え、ダブルクリックで概要へ移動します。タブで概要・操作履歴・解析へ移動でき、選択中IDとCSV内IDの不一致は表（橙）と上部に表示します。並べ替え・検索でも別のチップを誤って選択しません。測定前のチップは灰色、読めない履歴CSVは赤です。
- アプリ内で履歴を保存すると、そのチップだけを読み直して表に反映します（全件の再集計は不要）。AXNで測定した後は「一覧・履歴・集計を更新」で差分を取り込みます。
- 表の下の「分布・装置・測定者」: AXN相当の7種の分布（50区間）と装置・担当者別チップ数。検索で絞り込んだ対象を表示。読めなかったファイルは「読み込みエラー」に件数つきで分離
- 解析・トレンドの左にチップ一覧（IDで絞り込み・数字順）。列は チップID・実験数・選んだ操作の回数（例「FC 回数」）・最終使用日。見出しを押すとその列で並べ替え（数値は 1 回目で多い順、もう一度で逆順）、回数を比べてチップを選べます。回数は数値でない行も数えるので、グラフの n より多いことがあります。1 つ選ぶとそのチップがアプリ全体の選択になり、台帳に戻らずに上下キーで次々と見られます。Ctrl / Shift で複数選ぶと、最大 8 チップを色分けして同じグラフに重ね、凡例に回数・平均を出します（比較には横軸「日時」が向きます）。選んでいる行をもう一度クリックすると、その行だけが比較から外れます（最後の 1 つは外れません）
- 操作別・Info列別の数値トレンド。横軸は「回数（記録順）」と「日時」（各行の実験日時。年・月・日・時の切りのよい目盛り）を切り替え。縦軸は切りのよい間隔（0・20・40… や 0.2 刻みなど）の目盛り。最小・最大・平均を表示
- 行のダブルクリックで編集。行種別・行数・列数は維持
- CP932とCRLFで共有元へ保存。バックアップは `ChipDB/WorkbenchBackups`
- 読み込み後の外部変更を検知すると保存を拒否。再読み込みして編集し直してください
- UTF-8 BOMのCSVを書き出し可能

## チップIDの修正（2026-11-18〜）

決まりに合わないチップIDは、段階を踏んで直しています。手順と進み具合は [docs/chip_id_cleanup.md](../docs/chip_id_cleanup.md)。
旧名 → 新名の対応表は共有フォルダの `machinedb/PLAN/chip_aliases.json`（`shared/chip_aliases.py`）。台帳の「ID修正」列に、旧名には「→ 新名（状態）」、新名には「旧名 …」を出し、どちらの名前で検索しても両方が出ます。名前を直したチップは、台帳に旧名を `aliases` として残します。

## 編集・チェックイン

### 同期重複・指定IDの整理

上部の「重複・IDを整理…」で、`_DESKTOP…` と `(2)`・`(3)` 等のファイルを正規名と比較できます。
比較結果を選択し、確認後に統合します。完全一致する別名のコピーも、既知の重複グループに含めます。
同一記録の空欄は他方の列から補完し、固有の履歴を追加します。同じ元ファイル内の繰り返し記録は維持します。
同一記録の非空欄に異なる値があれば自動統合を停止します。GAP累積値は最大の値を保持します。

指定に基づくID修正は `chipdb/cleanup.py` の `ALIASES` に記録しています。
`sc49-3310-51`、`SC91-0000-10`、`SC77-4219-23`、`SC30-2315-35`、`SC25-2115-33` を正規の表記にしています。
SC77-4219-23の既知のNUL破損は、読める履歴を維持してCSV構造を修復します。失われた測定値は推定しません。

実行前に対象の元CSVを `ChipDB/WorkbenchBackups/cleanup_日時/originals/` に全件保存し、ハッシュを照合します。
統合結果を保存・照合した後で、重複側のCSVを削除します。外部更新を検出した場合は停止します。
チップ台帳の重複登録も統合し、手入力の管理情報は保持します。元台帳は `chip_info_before.json` に保存し、
AXN共通のロックとrevisionで更新します。手入力の管理情報に競合がある場合は台帳の更新を停止します。
`report.json`・`registry_changes.json` で処理済みの対象を確認できます。途中停止時もバックアップを保持します。
処理後は「一覧・履歴・集計を更新」を実行してください。

CLIからは `python tools/chipdb_cleanup.py --db D:\Qstatus\ChipDB\DB --report .tmp\chipdb-plan.json` で比較のみを行い、
`--apply` を付けるとバックアップ・統合・重複削除・台帳統合を実行します。

- 上部の「＋ チェックイン」、または「チップ台帳・比較」タブから測定前のチップを登録します。状態・保管場所・使用者・製作者（作成元）・主体（所属・管理する組織やグループ）・作製日・使用開始日・廃棄日・説明を保存できます。主体は 2026-11-18 に追加した項目で、AXN の共有台帳に一緒に保存されます（AXN は知らない項目も消さずに保存します）。日付は `YYYY-MM-DD`、未定は空欄です
- チェックインはAXNの先行登録と同じく共有ルートの `machinedb/PLAN/chip_info.json` に登録します。測定履歴CSVやGPSET、GAPは作成しません。新規IDの区切り文字はAXNと同じ形式（`-`）に統一します
- 履歴のない登録チップも台帳に表示します。概要には「なし（測定前）」を表示します。使用日検索は実際のExperiment行が対象なので、履歴のないチップはID・使用者などの検索または空欄で表示してください。
- 台帳で行を選び「選択チップの管理情報を編集」、またはダブルクリックで登録情報を修正できます。既存CSVのみのチップも管理情報を保存すると共有台帳に登録され、元CSVは維持されます
- 測定履歴の修正は「操作履歴・編集」で行を選び「選択行を編集」（またはダブルクリック）。元CSVをバックアップして保存します
- 複数行・列の修正は「操作履歴・編集」→「表全体を編集」。セルをダブルクリックして修正、Shift/Ctrlで行を範囲選択し、対象列の完全一致置換または同じ値の設定ができます。「全行」を指定すれば列全体が対象になります
- GAP列は先頭行の集計値とExperiment行を編集できます。日付のような異常値でも正しいGAP数は推測せず、確認した値に置換してください。先頭行と各操作行のGAPが同じとは限らないので、列全体を一つの値に揃える操作は必要な範囲だけに限定してください
- Excel等でGAP列の値を編集してコピーし、貼り付け開始の行をクリック、対象列を「GAP #」にして「貼り付け」で縦一列を反映できます。複数列のタブ区切り貼り付けにも対応。行数・列数、種別・チップID・見出しは保護します
- 表全体の変更は下書きで、「元に戻す」が可能。「変更内容を確認して保存」で行・列・変更前後を一覧確認し、保存ボタンを押すまで元CSVは変わりません。保存時にバックアップと外部更新チェックを行います。編集対象は選択した1チップの履歴全体です
- 台帳はAXNと同じ `chip_info.lock`・revisionを使って保存し、変更前の全台帳を `machinedb/PLAN/backups` にバックアップします。外部更新・重複チップ・競合候補ファイルを検知した場合は保存を停止します
- 集計列・分布は履歴CSVがあるチップを対象にします。AXNのChip Masterは保存済みスナップショットを表示するため、CSV履歴を編集した後にAXNへ反映するにはAXN側の「ChipDBの差分を確認・取込」を使ってください

Infoの意味と単位は操作によって異なります。トレンドグラフは数値の単純集計です。履歴CSVはAXNとの排他ロックを共有していないため、測定中の同時編集を避けてください。GPSETの作成・編集はAXNで行います。

チップ概要・台帳の集計列はAXNの `panel_info.py` に合わせ、Info1の `0 < CAL < 200`、`0 < FC < 3`、`0 < MA/TA < 100` だけを採用します。最新値は有効値のうちファイル順で最後の値です。操作件数には除外値の行も含めます。全チップ集計は取得時点の表示なので、編集やAXNでの測定後は集計を更新してください。スコア・外部解析結果の結合はまだ含みません。

## 操作間比較

「操作間比較」タブ左のチップID一覧でCtrl/Shiftを使って複数選択します。各操作の記録件数を表示し、ID検索や列見出しでの並べ替えができます。検索で隠れたチップの選択は保持し、「選択をすべて解除」で解除できます。

- **代表値の散布図のみ**: FC・MA・TA・CALからX/Y操作とInfo列を選択。1点は1チップで、選択した全履歴の中央値・平均・最初・最後の値から選びます。操作回数が異なっても全組み合わせは作りません。両操作がそろわないチップは除外し、その件数を表示します。Info1をAXN集計範囲に限定することもできます。
- プロット領域はウィンドウやペインをリサイズしても正方形を保ちます。右側に代表値一覧・履歴明細を配置し、点をクリックすると該当チップの元記録を表示します。履歴明細は500件ずつ表示し、CSV出力は代表値一覧を書き出します。
- 「点の直径」で2〜30 pxに調整できます（初期6 px）。「件数で絞る」はX/Yの条件適用後の有効数値件数に対して `>` / `>=` を適用します。初期条件は両方 `> 5`（各6件以上）で、チェックすると有効になります。Xのみ・Yのみ・どちらか一方も選択可能。「件数条件に合うチップを選択」は検索で表示中の一覧の全履歴件数を使って選択し、散布図の件数絞り込みも有効にします。
- 「代表値の範囲」でX下限・上限、Y下限・上限を指定して「範囲を適用」を押すと、代表値算出後の点を絞り込みます。空欄側は制限せず、境界値を含みます。範囲外のチップは散布図・代表値一覧・履歴明細・相関係数・CSVから除外し、件数を表示します。「範囲を解除」で全て戻せます。元の履歴CSVやチップ選択は保持します。
- 期間指定・履歴明細ではFC/MA/TA/CALの実施時刻（Info3）を優先し、欠落時は実験開始日時を代用したことを明示。期間指定時は日時不明の記録を除外します。
- 最初・最後は既存集計と同じく**履歴の記録順**。Pearson・Spearmanはチップ代表値間の相関であり、同一チップ内の測定間相関ではありません。3チップ未満または定数の場合は算出不可と表示します。
- 比較は共有CSVを読むだけです。原データの編集・自動的な測定ペア作成・因果の判定は行いません。代表値の計算は対象の履歴全件を使用します。時系列は既存の「解析・トレンド」で確認できます。
- 代表値一覧の行・散布図の点を選ぶと、そのチップが上部のチップになります（比較の複数選択はそのまま）。ダブルクリックまたは「上部のチップの概要へ」「台帳へ」でそのチップの情報へ移動します。

## 実験データ（ChipID → SQserver の逆引き、2026-11-19〜）

「実験データ」タブは、上部のチップの履歴CSVにある実験 ID（EXID）と操作（FC#5 など）から、FC・MA・TA・CALのデータがSQserverのどこにあるかを表示します。

- 探す順は AXN `axn/data_locations.py`・`scoring/experiment_files.py` と同じ: Tmp_backup のフォルダ → その zip → SQ_backup のフォルダ → その zip（Machine_N.csv）。
  その後に `data_stocked\ANn`（SQ_backup の `data` を `data_stocked` に替えた場所。2021年ごろの古い実験の zip。Machine_N.csv には載っていない）を探します。SQserver に届かないPCの一覧表示は data_stocked を含みません。
- 下の表に、選んだ実験のうちこのチップの操作の `R_`（結果）と `PM_`（50 msログ）を出します。zip内は `zipのパス :: FC/ファイル名`。
- 下の表で操作を選ぶと、その `PM_` ログをグラフにします（zip からはその1ファイルだけ読む）。上段は K Current (uA) の対数軸、下段は「下段の列」で選んだ列（初期は Piezo (V)、RM Motor・AM Motor・K Bias なども可）。時間軸は共通で、マウスを重ねるとその時刻の値を表示します。右の表は同じ操作の `R_` 結果（SHW・CAL Slope など）です。
- 下の表は FC・MA・TA・CAL・AC の操作に加えて、先頭に測定条件 `GPSET`（試料名・溶媒・カバー・装置・オペレーターなど）を出します。GPSET は履歴の操作に関係なく、そのフォルダの全ファイルです。同じ操作のやり直し（AC#1 が日時違いで複数など）は日時ごとに `PM_`・`R_` の組で並び、グラフは選んだ行と同じ日時の組を出します。
- 「選んだファイルを保存」は、この PC の保存先（初期は `ダウンロード\ChipAtlas`。「保存先を変える…」で変更、PCごとに `%LOCALAPPDATA%\QuantumWorkbench\chip_atlas_downloads.json` に記録）に `<ChipID>\<実験ID>\` フォルダを作り、ファイルをそのまま並べます。実験を1件選んだときは下の表で選んだ行（Ctrl / Shift で複数、Ctrl+A で全部）、実験を複数選んだときはそれぞれの全ファイルです。サーバー（UNC やネットワークドライブ）は保存先にできません。同じ大きさのファイルがすでにあれば写し直しません。zip は展開せず、必要なメンバーだけをコピーします。
- ダブルクリックで開くときは、その段のフォルダだけを作業場所 `%LOCALAPPDATA%\ChipAtlas\experiments\<実験ID>\` に取り出して開きます。
- SQserverに届かないPCでは、OUNmain03 が毎時書く `D:\Qstatus\database\Upload\<装置> SQ inventory.csv` で「どこにあるはずか」だけを表示します（フォルダかzipかは不明）。見つからない実験は、同じ実験日時で名前の違う候補を表示します。
- 読むだけです。SQserverのデータは変更しません。
